
# QuickNotes

QuickNotes is a simple and responsive note-taking web application built using HTML, CSS and JavaScript. It allows users to create, organise, search and delete notes easily. Notes can be grouped into Personal, Work and Study categories. The application uses localStorage to save notes so they remain available even after refreshing the page.

## Features

- Add notes with Personal, Work or Study categories.
- Display notes with their creation date and time.
- Delete individual notes.
- Search notes instantly without reloading the page.
- Save and restore notes using localStorage.
- Validate empty notes and notes exceeding 200 characters.
- Display the total number of saved notes.
- Responsive layout for desktop and mobile devices.
- Different colours for each note category.

## Technologies Used

- HTML5 for webpage structure.
- CSS3 for styling and responsive layouts.
- JavaScript for application functionality.
- Browser localStorage for data persistence.

## How to Run Locally

1. Clone the repository:

   git clone https://github.com/adeshissack27-arch/quicknotes-app.git

2. Open the quicknotes-app folder in VS Code.
3. Open index.html using Live Server or a web browser.
4. Enter a note, select a category and click Add Note.
5. Use the search field to find notes or Delete to remove them.
